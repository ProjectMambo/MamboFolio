I started [MamboSite](/project/mambosite) as an easy way to maintain my websites. previous workflow includes, maintaining the contents and code implementations. Current workflow only consists of maintaining content, code implementations is separated to be the target for MamboSite.

This blog mark the full use of MamboSite, [release v0.1.1](https://github.com/ProjectMambo/MamboSite/releases/tag/v0.1.1), and the full migration of [MamboFolio](/project/mambofolio) from manual code base to using MamboSite as the site generator.

That's it. Feel free to try out MamboSite.
